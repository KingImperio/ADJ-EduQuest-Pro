## 1. System Overview

ADJ EduQuest is a four-app browser-based system that handles the complete exam lifecycle — creation, distribution, taking, submission, grading, and results delivery — entirely through encrypted files, with no server required. Teachers, students, and admins interact through dedicated apps. Files pass between them via WhatsApp, email, or any transfer method.

Subjects with formulas, equations, and scientific notation — Mathematics, Physics, Chemistry, Biology — are fully supported through KaTeX rendering. Diagram-based questions support image embedding directly inside exam files.

### The Four Apps

| App | Purpose |
|-----|---------|
| **E-Quest Teacher** | Exam creation, question parsing, AI generation, grading, results export |
| **E-Quest Student** | Exam taking only — timed, monitored, offline-capable |
| **E-Quest Admin** | Teacher management, student registry, results management, analytics |
| **E-Quest Viewer** | Lightweight results viewer — students open .adjr files to see graded results |

### Core Principles

- **Offline First** — everything works without internet after initial page load. Files are the transport layer.
- **File-Based** — no database, no server. Encrypted JSON files carry all data between apps and people.
- **Mobile First** — built for phones. Most Nigerian students and teachers use mobile, not desktop.
- **AI-Augmented** — optional AI integration via teacher's own API key. Question generation and theory grading support.
- **Formula-Ready** — KaTeX renders mathematical and scientific notation natively in the browser. No extra setup for teachers or students.

### The Complete Exam Flow

```
1. Teacher creates exam — parses questions or generates via AI (with LaTeX formulas)
2. Teacher exports .adjx file — sends to students via WhatsApp or email
3. Student opens .adjx in E-Quest Student — identity checked, exam begins
4. Exam runs timed with monitoring — formulas render automatically — auto-submits at zero
5. Student exports .adjs file — sends back to teacher via WhatsApp or email
6. Teacher imports .adjs — auto-grading runs, AI assists theory, teacher reviews
7. Teacher exports .adjr results — sends to student and .adjb batch to admin
8. Student opens .adjr in E-Quest Viewer — sees full results with explanations and rendered formulas
```

## 2. File System

All files are JSON objects encrypted using AES-256 via the crypto-js library. A fixed app-level encryption key is used in v1 — upgraded to per-session keys in v2. Every file is human-unreadable when opened in a text editor but fully processable by the correct E-Quest app.

LaTeX formula strings are stored as plain text inside the JSON — rendering happens at display time, never at storage time.

### File Types

#### `.eqid` — Identity File
Teacher or Student identity. Generated on registration. Used for login by drag-and-drop or file select.

**Contains:** TID or SID, full name, registered subjects, centre code, contact details, permission level  
**Generated by:** Teacher App or Student App

---

#### `.adjx` — Exam File
The exam package. Contains all questions with hidden correct answers and explanations. Students cannot access `correctIndex` or `explanation` fields. Formula strings stored as LaTeX, images stored as base64.

**Contains:** Exam metadata, all questions with options, hidden correct answers, hidden explanations, LaTeX formula strings, base64 images (where applicable), teacher TID and contact, target subject and class  
**Generated by:** Teacher App → sent to Students

---

#### `.adjs` — Submission File
Student's completed exam. Contains all answers, time spent per question, integrity monitoring data, confidence rating. Cannot be edited after generation — submission hash prevents tampering.

**Contains:** Student SID and identity, all answers by question ID, time spent per question, tab switch log, focus time ratio, confidence rating (1-5)  
**Generated by:** Student App → sent to Teacher

---

#### `.adjr` — Results File
Graded results. Contains everything — original questions, student answers, correct answers, explanations, marks per question, total score, integrity report, teacher comments, AI feedback on theory answers. All formulas stored as LaTeX and rendered for the student in E-Quest Viewer.

**Contains:** Full question-answer comparison, marks per question, total score and percentage, grade, integrity report, AI feedback on theory, teacher comments  
**Generated by:** Teacher App → sent to Student

---

#### `.adjb` — Batch File
Batch results from teacher to admin. Contains multiple `.adjr` summaries plus class analytics.

**Contains:** Multiple student result summaries, class average, score distribution, per-question analytics, integrity flags summary, teacher TID  
**Generated by:** Teacher App → sent to Admin

## 3. Question Parser & Formula Rendering

The parser is the heart of the Teacher app. Teachers paste questions in a defined plain-text format and the parser converts them instantly into structured question cards. Formulas written in LaTeX notation render automatically via KaTeX.

### The Delimiter Change — Double Pipe `||`

The original single pipe `|` delimiter conflicts with LaTeX syntax for absolute values, matrices, and determinants (e.g., `|x|`, `|A|`). All E-Quest format questions use `||` (double pipe) as the delimiter.

```
MCQ || Question text || Option A || Option B ✅ || Option C || Option D || Marks || {Explanation}
```

Double pipe is virtually never used inside LaTeX formulas, eliminating all delimiter conflicts.

---

### Formula Syntax — LaTeX via KaTeX

Wrap any formula, equation, symbol, or scientific notation in `$$...$$`.

**KaTeX is loaded via CDN — one script tag in each app's HTML. No setup required from teachers or students.**

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/katex@0.16.9/dist/katex.min.css">
<script src="https://cdn.jsdelivr.net/npm/katex@0.16.9/dist/katex.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/katex@0.16.9/dist/contrib/auto-render.min.js"></script>
```

```javascript
function renderMath(element) {
  renderMathInElement(element, {
    delimiters: [
      { left: "$$", right: "$$", display: false }
    ],
    throwOnError: false // Shows raw LaTeX if render fails — exam never breaks
  });
}

// Call after injecting any question content into DOM
const questionEl = document.getElementById('question-text');
questionEl.innerHTML = question.text;
renderMath(questionEl);

// Render options too
document.querySelectorAll('.option-text').forEach(renderMath);
```

`throwOnError: false` is critical — if a teacher writes malformed LaTeX, the question still displays. It shows the raw `$$...$$` text instead of crashing. The exam never breaks because of a formula error.

### Format Examples — With Formulas

**Mathematics — MCQ:**
```
MCQ || What is the result of $$\frac{d}{dx}(x^2)$$? || $$x$$ || $$2x$$ ✅ || $$2x^2$$ || $$x^2$$ || 2 || {The power rule states $$\frac{d}{dx}(x^n) = nx^{n-1}$$. For $$x^2$$, n=2, giving $$2x$$}
```

**Physics — MCQ:**
```
MCQ || A body of mass 5kg accelerates at $$10ms^{-2}$$. What is the force? || $$25N$$ || $$50N$$ ✅ || $$5N$$ || $$100N$$ || 1 || {Using Newton's second law: $$F = ma = 5 \times 10 = 50N$$}
```

**Chemistry — MCQ:**
```
MCQ || What are the products of $$H_2SO_4 + 2NaOH \rightarrow$$ ? || $$NaSO_4 + H_2O$$ || $$Na_2SO_4 + 2H_2O$$ ✅ || $$2NaSO_4 + H_2O$$ || $$NaOH + H_2SO_4$$ || 2 || {Sulfuric acid + sodium hydroxide → sodium sulfate + water. This is a neutralisation reaction}
```

**Physics — FIB:**
```
FIB || Using $$v^2 = u^2 + 2as$$, if u=0, a=$$10ms^{-2}$$, s=20m, find v || $$20ms^{-1}$$ ✅ || 2 || {$$v^2 = 0 + 2(10)(20) = 400$$, therefore $$v = \sqrt{400} = 20ms^{-1}$$}
```

**Mathematics — MRQ:**
```
MRQ || Which of the following are quadratic equations? || $$x^2 + 3x + 2 = 0$$ ✅ || $$3x + 5 = 0$$ || $$2x^2 - x = 0$$ ✅ || $$x^3 - 1 = 0$$ || 2 || {A quadratic equation has degree 2 — the highest power of x is 2. Options A and C qualify. B is linear (degree 1). D is cubic (degree 3)}
```

**Chemistry — Theory:**
```
THE || Describe the mechanism of the reaction between $$HCl$$ and $$NaOH$$, including the ionic equation || 3 || {Ionic equation: $$H^+ + OH^- \rightarrow H_2O$$. HCl dissociates fully as a strong acid. NaOH dissociates fully as a strong base. The net ionic equation shows H⁺ and OH⁻ combining to form water. This is a neutralisation reaction with $$\Delta H < 0$$ (exothermic)}
```

### Image Embedding — Diagram Questions

For diagram-based questions (Biology diagrams, Physics circuit diagrams, geometric figures), teachers upload an image in the Manual tab. The app:

1. Accepts PNG or JPG upload
2. Compresses automatically via Canvas API — resized to max 800px width, JPEG at 70% quality
3. Converts to base64 string
4. Stores inside the question object in the `.adjx` JSON as `"image"` field
5. Displays above or below the question text in Student and Viewer apps

```json
{
  "id": "q7",
  "type": "MCQ",
  "text": "In the diagram above, identify the part labelled X",
  "image": "data:image/jpeg;base64,/9j/4AAQSkZJRgAB...",
  "imagePosition": "above",
  "options": ["Nucleus", "Mitochondria", "Cell membrane", "Ribosome"],
  "correctIndex": [1],
  "marks": 2,
  "explanation": "Label X points to the mitochondria, identifiable by its double membrane and folded inner membrane (cristae)."
}
```

**File size management:** A `.adjx` with 10 compressed images stays under 3MB — comfortably within WhatsApp's file size limit. Teachers are shown a running file size estimate as they add images.

**AI and diagrams:** AI cannot generate images into the format. Diagram questions are always added through the Manual tab with image upload. AI-generated questions from documents work for text and formula questions only. This is clearly communicated in the Teacher app.

### Parser Logic (Updated)

1. **Split input by newlines** — filter blank lines. Each non-empty line is one question.
2. **Split each line by `||`** — produces an array of elements. `line.split('||').map(e => e.trim())`
3. **Read element[0] as type** — validates against MCQ/MRQ/FIB/THE. Invalid type = error card.
4. **Element[1] is the question text** — may contain `$$...$$` LaTeX strings.
5. **For MCQ/MRQ: loop remaining elements** — find the number (marks) and `{}` block. Everything between question and marks is an option.
6. **Check each option for `✅`** — if present: record as correct, strip `✅` from display text.
7. **Auto-assign labels A, B, C, D** — options may contain `$$...$$` LaTeX strings.
8. **Extract `{}` content as explanation** — regex `/\{(.+?)\}/s` — stored separately, may contain LaTeX.
9. **Output: structured question object** — displayed as a preview card with formulas rendered via KaTeX.
10. **Call `renderMath(cardElement)`** — after each card is injected into the DOM.

## 4. AI Integration

AI is optional and entirely controlled by the teacher. They paste their own API key from OpenRouter, Hugging Face, or Google Gemini. The key is stored in their browser's localStorage — it never leaves their device and is never sent to any ADJ server (there is no ADJ server). All AI calls go directly from the teacher's browser to the chosen AI provider.

### Supported Providers

| Provider | Notes |
|----------|-------|
| **OpenRouter (Recommended)** | One key accesses GPT-4o, Claude, Gemini, Llama, Mistral and more. Free credits on signup. |
| **Google Gemini** | Gemini 1.5 Flash is free tier with generous limits. Good for schools on tight budgets. |
| **Hugging Face** | Open source models via Inference API. Good for privacy-conscious teachers. |
| **Custom Base URL** | Any OpenAI-compatible API. For local models (Ollama) or other providers. |

### AI Feature 1 — Question Generation from Document

Teacher uploads a PDF, DOCX, or image. App extracts text. Text is sent to AI with the full E-Quest format prompt including LaTeX rules. AI returns questions in E-Quest format with `$$...$$` notation for all formulas. Teacher pastes into Parser tab.

**Flow:**
1. Teacher uploads source document (PDF / DOCX / image / plain text)
2. App extracts readable text (PDF.js for PDFs, mammoth.js for DOCX)
3. App constructs AI prompt: full format instructions + extracted text
4. API call goes directly to teacher's chosen provider
5. AI response returned — E-Quest format questions with LaTeX formulas
6. Teacher sees result in copyable text box
7. Teacher copies and pastes into Parser tab
8. Parser processes normally, KaTeX renders all formulas in preview cards

### AI Feature 2 — Theory Answer Grading Assistance

For theory questions, AI receives: question text (including LaTeX), model answer, student response, total marks. AI returns structured JSON with suggested mark, points covered, points missed, and feedback. Teacher makes final decision.

**Flow:**
1. Teacher opens grading interface with imported `.adjs` and `.adjx`
2. Theory questions flagged as "Needs Review"
3. Teacher clicks a theory question
4. App sends to AI: question + model answer + student response + total marks
5. AI returns: suggested mark, points covered, points missed, feedback
6. Teacher sees AI assessment alongside their own reading
7. Teacher enters final mark — can use AI suggestion or override
8. AI feedback optionally included in `.adjr` results file

### AI Feature 3 — Explanation Generation

When a teacher creates a question manually without an explanation, they tap "Generate Explanation." AI receives the question and correct answer and generates a clear student-friendly explanation including relevant formulas in LaTeX notation.

### AI Feature 4 — Question Bank Expansion

Teacher enters a topic and difficulty level. AI generates additional practice questions in E-Quest format with proper LaTeX for formula-heavy subjects. Teacher reviews, accepts, or rejects each generated question.

### The Complete AI Prompt — Teachers Copy This

```
Convert the following exam questions to E-Quest format exactly.

DELIMITER: Use || (double pipe) to separate all elements — NOT single |

FORMAT: TYPE || Question || Option ✅ || Option || Option || Option || Marks || {Explanation}

QUESTION TYPES:
- MCQ: one correct answer
- MRQ: multiple correct answers — mark every correct one with ✅
- FIB: fill in the blank — use ___ in question, give correct answer with ✅
- THE: theory/essay — no options, just marks and explanation (model answer)

MARKS: 1 (easy/recall)  2 (medium/application)  3 (hard/analysis — use sparingly)

ALWAYS add explanation in {} — include why wrong answers are wrong where relevant.

FORMULA RULES — apply to Maths, Physics, Chemistry, Biology:
- Wrap ALL formulas, equations, symbols in $$...$$
- Superscript: $$x^2$$   Subscript: $$H_2$$
- Fraction: $$\frac{numerator}{denominator}$$
- Square root: $$\sqrt{x}$$
- Chemical reaction arrow: $$\rightarrow$$
- Equilibrium: $$\rightleftharpoons$$
- Units with negative powers: $$ms^{-2}$$  $$kgm^{-3}$$  $$mol^{-1}$$
- Greek letters: $$\alpha$$ $$\beta$$ $$\theta$$ $$\pi$$ $$\lambda$$ $$\Delta$$ $$\mu$$ $$\omega$$
- Multiplication: $$\times$$ or $$\cdot$$
- Plus/minus: $$\pm$$    Approximately: $$\approx$$
- Proportional: $$\propto$$    Infinity: $$\infty$$
- Degree: $$90^\circ$$
- Integral: $$\int_a^b f(x)dx$$
- Summation: $$\sum_{i=1}^{n}$$
- Absolute value: $$\mid x \mid$$ (use \mid NOT | to avoid delimiter conflict)
- Vector: $$\vec{v}$$

EXAMPLES:
MCQ || What is $$\frac{d}{dx}(x^3)$$? || $$x^2$$ || $$3x^2$$ ✅ || $$3x$$ || $$x^3$$ || 2 || {Power rule: $$\frac{d}{dx}(x^n) = nx^{n-1}$$. Here n=3, result is $$3x^2$$}

MCQ || A 2kg mass accelerates at $$5ms^{-2}$$. Force = ? || $$2.5N$$ || $$10N$$ ✅ || $$7N$$ || $$25N$$ || 1 || {$$F = ma = 2 \times 5 = 10N$$}

FIB || The chemical formula for water is ___ || $$H_2O$$ ✅ || 1 || {Water consists of 2 hydrogen atoms bonded to 1 oxygen atom: $$H_2O$$}

No numbering. No brackets. One question per line.

QUESTIONS TO CONVERT:
[PASTE YOUR QUESTIONS HERE]
```

### AI Call Structure

```javascript
const apiKey = localStorage.getItem('eq_api_key');
const baseURL = localStorage.getItem('eq_api_url') || 'https://openrouter.ai/api/v1';

async function callAI(systemPrompt, userContent) {
  const response = await fetch(`${baseURL}/chat/completions`, {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${apiKey}`,
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({
      model: localStorage.getItem('eq_model') || 'google/gemini-flash-1.5',
      messages: [
        { role: 'system', content: systemPrompt },
        { role: 'user', content: userContent }
      ],
      max_tokens: 3000
    })
  });
  const data = await response.json();
  return data.choices[0].message.content;
}

// Theory grading
const feedback = await callAI(
  `You are an exam grader. Given a question, model answer, and student response, return JSON only:
   {
     "suggestedMark": number,
     "pointsCovered": ["point1", "point2"],
     "pointsMissed": ["point1", "point2"],
     "feedback": "2-3 sentence constructive feedback"
   }
   Be specific. Reference the model answer directly. Total marks available: ${question.marks}`,
  `Question: ${question.text}
   Model Answer: ${question.explanation}
   Student Response: ${studentAnswer}`
);
```

## 5. Identity System

There are no passwords in ADJ EduQuest. Your `.eqid` file IS your identity. Drag and drop it or select it to log in from any device.

### Teacher ID — TID

**Format:** `TQ-[DEPT]-[4 digits]-[YEAR]`  
**Examples:** `TQ-SCI-4821-26` / `TQ-ENG-3310-26` / `TQ-MAT-7744-26`

**Registration Flow:**
1. Teacher opens E-Quest Teacher app
2. Enters: full name, tutorial centre code (from admin), department, subjects they teach, email, WhatsApp number
3. App generates unique TID
4. App generates `.eqid` file — encrypted JSON with all profile data
5. File auto-downloads: `[Name]-Teacher.eqid`
6. TID displayed on screen with instructions to save the file safely
7. Teacher appears in Admin as "Pending Approval"
8. Admin approves — teacher can now export exams
9. Until approved: TID marked unverified, exam export disabled

### Student ID — SID

**Format:** `SQ-[CLASS]-[4 digits]-[YEAR]`  
**Examples:** `SQ-SS3-7734-26` / `SQ-SS2-1129-26` / `SQ-JSS3-8821-26`

**Registration Flow:**
1. Student opens E-Quest Student app
2. Enters: full name, class, department, email, WhatsApp number
3. Selects exam types (WAEC / JAMB / NECO / GCE — multiple allowed)
4. Selects all their subjects from a full Nigerian curriculum list
5. App generates unique SID
6. App generates `.eqid` file — auto-downloads: `[Name]-Student.eqid`
7. Student is active immediately — no admin approval needed

### Subject Mismatch Detection

When a student opens an `.adjx` file, the app compares the exam's subject against subjects in the student's `.eqid`. Mismatch = exam blocked.

**Screen shown:**
```
This exam is for: CIVIC EDUCATION

Civic Education is not in your registered subjects.
This exam may not be intended for you.

Your SID: SQ-SS3-7734-26
Your Name: Chidi Okeke

[Message Teacher on WhatsApp ↗]
```

**Pre-filled WhatsApp message:**
```
Hello Mr. Adeyemi, I am Chidi Okeke (SID: SQ-SS3-7734-26). 
I received your Civic Education exam but this subject is not in my 
registered subjects. Please confirm if this was sent to me correctly.
```

## 9. Grading & Results

### Auto-Grading Logic by Question Type

| Type | Logic | Edge Cases |
|------|-------|------------|
| **MCQ** | Selected index === correct index. Full marks or zero. | No selection = zero, flagged as unattempted. |
| **MRQ** | `(correct selected - wrong selected) / total correct × total marks`. Minimum zero. | 3 correct exist. Student picks 2 correct + 1 wrong = (2-1)/3 × marks. Rounded to nearest 0.5. |
| **FIB** | Case-insensitive string comparison, whitespace trimmed. | Levenshtein distance ≤ 2 = flagged for teacher review, not auto-failed. |
| **THE** | Cannot auto-grade. Flagged "Pending Teacher Review". AI assistance available. | Teacher sees question + model answer + student response side by side. Formulas rendered in all three. |

### Integrity Report Levels

| Level | Conditions |
|-------|------------|
| 🟢 **CLEAN** | 0–1 tab switches, no copy attempts, focus time >90% |
| 🟡 **MINOR** | 2–3 tab switches OR 1–2 copy attempts |
| 🟠 **MODERATE** | 4–6 tab switches OR 3+ copy attempts OR focus time 70–90% |
| 🔴 **SIGNIFICANT** | 7+ tab switches OR paste in theory OR focus time <70% |

> The app reports. The teacher decides. Integrity data is advisory — not automatic penalty.

### What Student Sees in E-Quest Viewer
- Score: `47/60 — 78%`
- Grade badge
- Performance summary: correct, partially correct, wrong, unattempted
- Confidence vs Performance: "You rated confidence 4/5 and scored 78%"
- Per-question breakdown — **all formulas rendered via KaTeX**
- Correct: green / Wrong: red + correct answer shown + full explanation
- Theory: student answer + model answer + AI feedback + teacher mark + teacher comments
- Integrity summary shown transparently
- Teacher comments at top

## 10. Theory Exams

Theory exams are separate exam sets using only THE question type. Everything else — file format, identity system, delivery — is the same.

### How Theory Exams Differ

| Aspect | Detail |
|--------|--------|
| **Creation** | THE questions only. Each must have a model answer in the explanation field. Formulas supported in both question and model answer. |
| **Student Experience** | Large text areas. Word count shown. No options. Spell-check active. Students can write and format text freely. |
| **Time** | Fewer questions, longer duration. A 3-question theory exam might be 60–90 minutes. |
| **Grading** | All questions require teacher review. AI assistance strongly recommended. |
| **Results** | `.adjr` includes AI feedback. Student sees model answer, their answer, what they covered, what they missed. |

### AI Theory Grading — Response Fields

| Field | Description |
|-------|-------------|
| `suggestedMark` | Numerical mark out of total marks |
| `pointsCovered` | Specific points from model answer the student addressed |
| `pointsMissed` | Key points from model answer the student did not address |
| `feedback` | 2–3 sentences of constructive, accessible feedback |

Teacher's entered mark is the only mark that goes into `.adjr`. AI is advisory.

## 11. Security

E-Quest's security is calibrated for its context: a classroom setting. Not designed against sophisticated attackers — designed against a student who knows how to open DevTools.

### Security Layers

| Layer | Level | Detail |
|-------|-------|--------|
| **File Encryption** | Solid | AES-256 via crypto-js. All `.adj*` files are gibberish in a text editor. |
| **Answer Key Isolation** | Solid | Student app never renders `correctIndex` or `explanation` fields. They exist in encrypted payload but are filtered before any rendering. |
| **Submission Integrity Hash** | Strong | SHA-256 hash of answers + timestamp + SID. Edited `.adjs` files produce invalid hashes — flagged on import. |
| **Identity Binding** | Solid | `.adjr` results bound to student SID. Cannot be opened by wrong student in Viewer. |
| **API Key Privacy** | Strong | Stored in localStorage only. Never in any `.adj` file. Never sent to ADJ servers. |
| **Monitoring Data** | Solid | Tab switches, copy attempts, focus time in `.adjs`. Cannot be altered post-submission due to hash. Students warned at exam start. |

### Honest Limitations

> ⚠️ A student using a second device to look answers up cannot be detected — requires physical invigilation.

> ⚠️ A student who extracts the decryption key from JavaScript source can decrypt exam files — requires significant technical effort.

> ⚠️ Browser localStorage can be cleared accidentally — students should backup `.eqid` safely.

> ⚠️ This is appropriate for a tutorial centre. Not appropriate for JAMB or WAEC — those require dedicated secure CBT infrastructure.
